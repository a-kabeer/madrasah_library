That template is the staff application: it opens a sidebar of management links, a notification bell, a user menu and an `hx-boost` wrapper that fetches every link in the background into `#mainContent`. None of that belongs on a page a stranger opened, and inheriting from it and then hiding the parts would leave the hiding as the only thing between a visitor and the shape of the staff application. So this is a separate document that happens to share a stylesheet. What is shared: Bootstrap, the project's own style.css, and `branding` from the context processor. What is not: the shell, the navigation, the modals, the toast area, the barcode scanner, app.js and htmx. No JavaScript at all. Every link here is an ordinary link and every form an ordinary GET form, so search, filtering and pagination work with scripting switched off - there is nothing to fall back *to*, because nothing was intercepted in the first place. That is also why no element on these pages carries `hx-` anything, and why nothing targets `#mainContent`: the id does not exist in this document. Fixed light theme. This page loads no JavaScript at all - by design, and there is a test that keeps it that way. The topbar switcher is a Bootstrap dropdown, so on this page it would render a button that cannot open: dead UI. It also posts, and every POST form brings a CSRF token, which would break the three properties this catalogue is built around - one GET form and nothing else, no token, and an archived book's page being byte-identical to an unused id's. A public switcher therefore has to be scriptless and formless: plain links carrying the language in the query string, honoured per-request without touching the session. That is a small change and it is not made here, so for now an anonymous reader gets the language their browser asks for. {% endcomment %}
