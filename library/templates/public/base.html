{% load static %} {% comment %} The public catalogue's own document, deliberately not `library/base.html`. That template is the staff application: it opens a sidebar of management links, a notification bell, a user menu and an `hx-boost` wrapper that fetches every link in the background into `#mainContent`. None of that belongs on a page a stranger opened, and inheriting from it and then hiding the parts would leave the hiding as the only thing between a visitor and the shape of the staff application. So this is a separate document that happens to share a stylesheet. What is shared: Bootstrap, the project's own style.css, and `branding` from the context processor. What is not: the shell, the navigation, the modals, the toast area, the barcode scanner, app.js and htmx. No JavaScript at all. Every link here is an ordinary link and every form an ordinary GET form, so search, filtering and pagination work with scripting switched off - there is nothing to fall back *to*, because nothing was intercepted in the first place. That is also why no element on these pages carries `hx-` anything, and why nothing targets `#mainContent`: the id does not exist in this document. Fixed light theme. The staff shell resolves a theme from a signed-in user's stored preference and a localStorage mirror; a visitor has neither, and running that script here would mean shipping script to a page that needs none. {% endcomment %} {% block title %}{{ branding.display_name }}{% endblock %} {% comment %} The organisation's colours, exactly as the staff shell injects them, so the two surfaces look like one institution. {% endcomment %} {% if branding.has_custom_colors %} {% endif %}
