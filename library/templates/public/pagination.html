Its own, rather than `library/partials/pagination.html`: that one takes a `swap` flag and puts `hx-get` on every link, and this surface has no htmx in it at all. Here each link is only an `href`, which is what makes paging work with scripting switched off. `pagination_query` is the current query string minus `page`, so a search and its filters survive being paged through.
