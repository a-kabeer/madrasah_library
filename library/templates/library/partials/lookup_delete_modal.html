The confirm posts and swaps this body, so a blocker that appeared in the meantime — somebody else filing a book under this name a moment ago — replaces the button with the explanation instead of throwing an error. A successful post answers with no content and an event, which closes the dialog and redraws the list. See `lookup_deleted_response`.
