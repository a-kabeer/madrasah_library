{% load i18n %} {% comment %} Move one copy to a different shelf, in a dialog. Only the shelf. The volume it is a copy of and the code on its label are not this dialog's business — one decides which book a past loan appears to have been for, and the other is printed on the book itself. Location and Shelf are two dropdowns because a shelf belongs to a location: choosing the location reloads the shelves for that location only, from `shelf_list`, so a copy cannot be filed somewhere it cannot be. The same endpoint and the same two partials the Add and Edit dialogs use, and the view checks the pair again on submit — the dropdowns only offering matching pairs is the browser's word for it, not a rule. Bulk move is a separate control on the list and is untouched: it moves the copies ticked there, which is a different question from this one. Expected context: copy, volume_name, locations, shelves, location_id, errors, error. {% endcomment %}
