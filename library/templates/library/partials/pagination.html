{% comment %} Bootstrap pagination for the book list. Separate from the older `_pagination.html`, which renders plain-text links and is still included by twelve unmigrated pages — replacing it wholesale would change all of them at once. Each link carries both `href` and `hx-get`. HTMX uses the latter to swap a new page of results in without a reload, taking the target and swap style from the #bookResults container this include sits inside; the href is what makes the link real — shareable, middle-clickable, and still working if the script never arrives. Anything else adopting this include needs a container like that, or the swap has nowhere to go.
