{% load i18n %} {% comment %} Bootstrap pagination for the book list. Separate from the older `_pagination.html`, which renders plain-text links and is still included by twelve unmigrated pages — replacing it wholesale would change all of them at once. Pass `swap=True` from inside a container that sets hx-target/hx-swap, and each link also gets an `hx-get` so a new page arrives without a reload. Leave it off and the links are ordinary navigation — which is what a page with no such container needs, since an hx-get with nowhere to go swaps the link into itself. Either way the `href` is real: shareable, middle-clickable, and still working when the script never arrives.
