Beside the theme selector and built the same way - the Bootstrap dropdown the topbar already uses - but working differently underneath, and the difference is the point. A theme is applied by the browser, so that control changes the page itself and saves in the background. A language is applied by the *server*: the page in front of the reader is already rendered in the old one, so choosing a language has to fetch the page again. Each option is therefore a real form submission, which is also what makes it work with no JavaScript at all. One form, not one per language.
