A librarian has one of them at a time. There are no links and no buttons here at all. Inside a dialog a link is a trap: following it throws the dialog away, and with it whatever the reader was in the middle of. And every action a librarian takes on a copy is in the list's own Actions column, so repeating them here would be the one duplication this list should not have. This dialog is for reading; the row is for acting. The timeline shows its first page. Paging it inside a dialog would mean a second copy of the pagination partial that knows how to swap a modal body; `history_total` says how many there are so nothing looks complete when it is not.
