{% load i18n %} {% comment %} Add or Edit an author, a category or a publisher, served into #formModal. One template behind all six of those, because they are one form: a name, and — for a publisher — a city. Which of the six this is comes in as `label`, `editing` and `has_city`, so there is nothing here that knows about any particular one of the three. The form posts to `action` with `?modal=1` and swaps itself. That is what keeps a rejected name in the dialog with the reason beside it, instead of throwing the dialog away and the typing with it. A successful post answers with no content at all and an event, which closes the dialog and redraws the list behind it — see `lookup_saved_response`. `hx-disinherit="*"` stops anything nested picking these up, and stops the shell's own `hx-boost` reaching down: without it the Cancel button and any link inside would try to navigate the main-content region from inside a dialog. Expected context: kind, label, action, editing, error, name, city, has_city. {% endcomment %}
