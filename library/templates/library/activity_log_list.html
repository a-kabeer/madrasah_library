{% extends layout %} {% load i18n %} {% comment %} The Activity Log, on the same card-and-table pattern as the book list. What changed is not only the styling. The old page printed the row as it is stored: ID: 143 - User: Ali - Action: UPDATE - Entity: BookCopy - ID: 858 Every one of those is a fact about the database rather than about the library. A librarian asking "what happened to that book?" cannot use an entity id, and does not need the log row's own id at all. So the page shows four things: when, who, what happened, and a way to reach the record. "What happened" is the `description` the writing side already stores, and it is already a sentence - "LIB-000858 returned from Suhaib Sindhi", "Zaid Baloch reserved Principles of Islamic Legal Theory". It was being shown last, after four fields of machinery. Here it is the column the eye lands on. The record type stays, small and under the description, because "which copy" and "which book" are different questions and the description does not always say which kind of thing it names. The entity id is gone: where a record still exists the description is a link to it, and where it does not - every DELETE - an id is of no use to anybody. {% endcomment %} {% block title %} {% translate "Activity Log" %} | {{ branding.display_name }} {% endblock %} {% block page_title %} {% translate "Activity Log" %} {% endblock %} {% block content %}
