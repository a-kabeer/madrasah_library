Read top to bottom it answers four questions in order: who am I and what is the one thing I do most (Header), how big is the library right now (Library Pulse), what needs a decision today (Action Center and Circulation Today), and what is the collection doing over time (Collection Health). Every number is a link to the page that owns the records behind it, and no section lists rows the owning page already lists in full. Nothing here computes anything. The counts are the view's, which are the same conditional aggregates the copy list, the loan list and the condition report use, so a figure here and the list it opens agree. Feature gating is `allowed_features`, the same set the sidebar reads, so a card is never offered for a page the role cannot open - and the analytics-derived section is gated in the view as well, because that data should not reach the template at all for a role without it. {% endcomment %}
