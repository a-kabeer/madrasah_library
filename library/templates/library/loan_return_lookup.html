The shape is the issue form's, because the desk's problem is the same one: somebody arrives with more than one book, and finding the second must not lose the first. So the loans picked so far ride in the query string, the search adds to that list rather than replacing it, and one submission records the lot - all of them or none. Every row does one thing, which is add itself to the list. * the return list, with the date and the note that apply to all of it.
